Support

Something not working, or an idea for a palette? Write to usableutilities@gmail.com. Please include your macOS version, Tinta's version (Tinta › About) and the editor involved. Replies usually within a few working days.

Requirements

macOS 14 Sonoma or later. Each editor must be installed separately; Tinta does not include or install them.

Frequently asked questions

How do I apply a theme?

Open “Linked editors” (Editor collegati), press “Link” (Collega) on an editor and choose the folder macOS suggests. Then pick a palette and press “Apply” (Applica). You link each editor only once.

Why does Tinta ask for folders?

Tinta runs in Apple's App Sandbox: it can write only to folders you choose. Each folder is used only for that editor's theme and settings files.

How do I undo everything?

Press “Unlink” (Scollega) on an editor. Tinta removes exactly what it added, restores the copy of your settings it saved, and forgets the folder.

The Claude Code tab does not change.

The Code tab is themed by the free Tinta plugin for Claude Code. After linking ~/.claude, start a new session in the Code tab (or restart the Claude app) so Claude Code loads the plugin. You can also install the plugin yourself in Claude Code; Tinta shows the steps.

VS Code, Cursor, Windsurf or VSCodium need a restart.

Without the companion extension the theme is applied when the editor reloads its window. Install the free “Tinta – Code Themes” extension from the Visual Studio Marketplace or Open VSX to switch instantly and color the whole interface.

JetBrains IDEs need a restart.

Without the companion plugin Tinta writes the editor color scheme, which the IDE reads at startup. The free Tinta plugin from the JetBrains Marketplace switches instantly and also colors panels and toolbars.

Xcode does not pick the theme.

Choose the “Tinta” theme once in Xcode › Settings › Themes. After that, Apply updates it.

Terminal, iTerm2, Ghostty, Warp, Zed, zsh

iTerm2, Ghostty, Warp and Zed pick up the Tinta theme by themselves. For Terminal press “Update Terminal” (Aggiorna Terminale). For the zsh prompt, Tinta adds one line to ~/.zshrc only if you click the button, or uses your Starship palette.

What does Tinta Pro include?

Tinta is free with the complete Salvia palette. Tinta Pro is a one-time in-app purchase that unlocks every palette and style, future palettes, sounds, effects and custom themes. Updates are included; there is no subscription.

How do I restore Tinta Pro on another Mac?

Sign in with the same Apple Account in the App Store and press “Restore Purchases” in Tinta's Store. Refunds are handled by Apple at reportaproblem.apple.com.

Can I turn sounds off?

Sounds (Tinta Pro) are off by default. Turn them on or off in the app's settings or in the theme editor.

Is my data collected?

Only anonymous usage statistics (no personal data, no tracking), which you can turn off with “Invia statistiche anonime” in Settings. See the privacy policy.

Supporto

Qualcosa non va, o hai un'idea per una palette? Scrivi a usableutilities@gmail.com. Indica la versione di macOS, quella di Tinta (Tinta › Informazioni) e l'editor coinvolto. Di solito rispondiamo entro pochi giorni lavorativi.

Requisiti

macOS 14 Sonoma o successivo. Ogni editor va installato a parte: Tinta non li include e non li installa.

Domande frequenti

Come applico un tema?

Apri «Editor collegati», premi «Collega» su un editor e scegli la cartella che macOS propone. Poi scegli una palette e premi «Applica». Ogni editor si collega una volta sola.

Perché Tinta chiede delle cartelle?

Tinta funziona nella App Sandbox di Apple: può scrivere solo nelle cartelle che scegli tu. Ogni cartella serve solo per i file di tema e di impostazioni di quell'editor.

Come annullo tutto?

Premi «Scollega» su un editor. Tinta toglie esattamente cio` che ha aggiunto, ripristina la copia delle impostazioni che aveva salvato e dimentica la cartella.

La scheda Code di Claude non cambia.

La scheda Code prende i colori dal plugin Tinta per Claude Code, gratuito. Dopo aver collegato ~/.claude apri una nuova sessione nella scheda Code (o riavvia l'app Claude) perché Claude Code carichi il plugin. Puoi anche installare il plugin da te in Claude Code: Tinta mostra i passaggi.

VS Code, Cursor, Windsurf o VSCodium vanno riavviati.

Senza l'estensione compagna il tema si applica quando l'editor ricarica la finestra. Installa l'estensione gratuita «Tinta – Code Themes» dal Visual Studio Marketplace o da Open VSX per il cambio istantaneo e i colori di tutta l'interfaccia.

Gli IDE JetBrains vanno riavviati.

Senza il plugin compagno Tinta scrive lo schema colori dell'editor, che l'IDE legge all'avvio. Il plugin Tinta gratuito dal JetBrains Marketplace cambia tema all'istante e colora anche pannelli e barre.

Xcode non prende il tema.

Scegli una volta il tema «Tinta» in Xcode › Settings › Themes. Da li` in poi Applica lo aggiorna.

Terminale, iTerm2, Ghostty, Warp, Zed, zsh

iTerm2, Ghostty, Warp e Zed prendono il tema Tinta da soli. Per Terminale premi «Aggiorna Terminale». Per il prompt di zsh Tinta aggiunge una riga a ~/.zshrc solo se premi il pulsante, oppure usa la tua palette di Starship.

Cosa include Tinta Pro?

Tinta è gratis con la palette Salvia completa. Tinta Pro è un acquisto in-app unico che sblocca ogni palette e stile, le palette future, suoni, effetti e temi personalizzati. Aggiornamenti inclusi, nessun abbonamento.

Come ripristino Tinta Pro su un altro Mac?

Accedi all'App Store con lo stesso Account Apple e premi «Ripristina acquisti» nello Store di Tinta. I rimborsi li gestisce Apple su reportaproblem.apple.com.

Posso spegnere i suoni?

I suoni (Tinta Pro) sono spenti di serie. Si accendono e si spengono nelle impostazioni dell'app o nell'editor del tema.

Raccogliete dati?

Solo statistiche d'uso anonime (niente dati personali, niente tracciamento), che spegni con «Invia statistiche anonime» nelle Impostazioni. Vedi l'informativa sulla privacy.
