One theme, all your editors.

Tinta is a Mac app that gives your code editors and terminals the same look. Pick a palette and a style, tweak any color, apply it in one click – and undo it just as easily.

Download on the Mac App Store

Palettes and styles for every mood, with more on the way. Minimal, Outline, Solid and Gradients, with live previews of code, chat and terminal before anything is applied.
One theme, everywhere you code: Visual Studio Code, Cursor, Windsurf, VSCodium, Kiro, Antigravity, Trae, JetBrains IDEs, Xcode, Zed, the Claude desktop app’s Code tab and Claude Code (via the free, open-source Tinta plugin), Terminal, iTerm2, Ghostty, Warp and the zsh prompt.
Free to start. The complete Salvia palette, in every style, is free. Tinta Pro is one in-app purchase, once: every palette and style, future palettes, sounds, effects and your own custom themes. Updates included, no subscription.
Safe and private. Tinta writes only theme and settings files, in folders you choose, keeps a copy before changing a setting and restores everything when you unlink. No account, no tracking; only anonymous usage statistics, which you can turn off.

Un tema, tutti i tuoi editor.

Palette e stili per ogni gusto, e altri in arrivo. Minimal, Outline, Solid e Sfumature, con anteprime dal vivo di codice, chat e terminale prima di applicare qualsiasi cosa.
Un tema, ovunque scrivi codice: Visual Studio Code, Cursor, Windsurf, VSCodium, Kiro, Antigravity, Trae, gli IDE JetBrains, Xcode, Zed, la scheda Code dell'app desktop Claude e Claude Code (tramite il plugin Tinta, gratuito e open source), Terminale, iTerm2, Ghostty, Warp e il prompt di zsh.
Gratis per iniziare. La palette Salvia completa, in tutti gli stili, è gratis. Tinta Pro è un solo acquisto in-app, una volta: ogni palette e stile, le palette future, suoni, effetti e i tuoi temi personalizzati. Aggiornamenti inclusi, nessun abbonamento.
Sicura e riservata. Tinta scrive solo file di tema e di impostazioni, nelle cartelle che scegli tu, conserva una copia prima di cambiare un'impostazione e ripristina tutto quando scolleghi. Nessun account, nessun tracciamento; solo statistiche d'uso anonime, che puoi spegnere.
