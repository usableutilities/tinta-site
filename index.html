FAQ

Questions, answered.

Which editors and terminals does Tinta support?

Visual Studio Code and its forks (Cursor, Windsurf, VSCodium, Kiro, Antigravity, Trae), JetBrains IDEs such as IntelliJ IDEA, PyCharm and WebStorm, Xcode, Zed, the Code tab of the Claude desktop app and Claude Code in the terminal, Terminal, iTerm2, Ghostty, Warp and the zsh prompt. Each editor is installed separately; Tinta does not include them.

Will Tinta change anything without asking?

No. Nothing changes until you link a tool, and macOS asks you to choose each folder. Tinta writes only theme and settings files, keeps a copy before changing a settings file, and “Unlink” removes exactly what it added.

What is free, and what does Tinta Pro add?

Tinta is free with the Salvia theme in every style, and every theme in the gallery can be previewed for free. Tinta Pro unlocks every theme in the gallery, including future ones, plus sounds, effects and your own custom themes.

Is Tinta Pro a subscription?

No. It is a one-time in-app purchase with updates included. To use it on another Mac, sign in with the same Apple Account and press “Restore Purchases” in Tinta's Store.

Do I need the companion extensions?

No, they are optional and free. Without them the theme applies when the editor reloads; with them VS Code-family editors and JetBrains IDEs switch instantly and color their whole interface. The Claude Code tab uses the free, open-source Tinta plugin for Claude Code.

Does Tinta collect data?

Only anonymous usage statistics, with no personal data and no tracking, which you can turn off in Settings. See the privacy policy.
